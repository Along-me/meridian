Meridian 1.2.0 是首个支持 GitHub 更新检测的版本。

- 新增启动时自动检查及手动检查更新，入口在“助手设置 → 版本与更新”。
- 发现新版后，点击下载，再点击退出并安装；不会静默安装。
- 新增货币转换：多数据源与自定义接口、手动导入、10 天缓存和历史参考值兜底。
- 工具快捷键按导航顺序统一管理，覆盖日期时间、时间戳、时间对照表、货币转换及挂件召回。
- 包含近期挂件透明背景、顶部菜单、拖动和托盘召回优化。

安装：下载 `Meridian-Setup-1.2.0-x64.exe`，适用于 Windows 10/11 x64。

1.1.5 及之前版本请手动安装此次新版一次，后续即可在软件内检测更新。升级保留已有配置。

`.blockmap` 和 `latest.yml` 用于客户端更新，无需手动运行。汇率仅供参考，实际日期与来源以界面显示为准。
