# macOS 未签名测试版

- Apple 芯片（M1/M2/M3/M4 等）：下载名称含 `arm64` 的 DMG 或 ZIP。
- Intel Mac：下载名称含 `x64` 的 DMG 或 ZIP。
- DMG 打开后把 Meridian 拖入“应用程序”。ZIP 解压后也可把 Meridian.app 移入“应用程序”，再打开。

这是没有 Apple 开发者证书签名、没有公证的预发布测试版。Apple 芯片所需的本地 ad-hoc 签名不代表经过 Apple 验证。首次打开可能被 macOS 安全检查阻止；确认来源后，可在“系统设置 → 隐私与安全性”中查看系统提供的打开选项。

支持多时区挂件、转换工具、菜单栏召回、隐藏顶部栏、贴边吸附及隐藏。菜单栏图标的菜单可打开管理界面或退出；关闭管理窗口后应用继续运行。贴边隐藏时窗口完全收起，鼠标靠近原位置边缘召回。开机启动需要在管理页手动开启，macOS 可能要求在系统登录项中批准。

此测试版通过 GitHub 手动下载更新，不提供自动下载安装。测试包独立于 Windows 正式发布，不改变 Windows 最新版。

构建机检查包括匹配芯片架构的应用启动、四种样式、贴边隐藏/召回、原生信息气泡及打包完整性。多显示器、全屏应用、Spaces 切换和真实登录启动仍需要在你的 Mac 上试用验证。
